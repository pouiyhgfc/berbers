Bij het boek van Mourigh & Kossmann horen afkortingen die je in de voorbeeldzinnen tegenkomt. Deze kaart legt ze uit, met de bijbehorende voorbeelden uit het boek.

### De afkortingen

| Afkorting | Betekenis |
| --- | --- |
| SG / PL | enkelvoud / meervoud |
| M / F | mannelijk / vrouwelijk |
| 1, 2, 3 | eerste, tweede, derde persoon |
| FS / AS | vrije staat / verbonden staat (les 13) |
| P | perfectief (les 07) |
| I of l | imperfectief (les 07) |
| A | aorist (les 08) |
| DO / IO | lijdend voorwerp / meewerkend voorwerp (les 25) |

Zo betekent "3SG:F" dus: derde persoon enkelvoud vrouwelijk — "zij". En een zin met "(ad + A)" erachter gebruikt het partikel `ad` plus de aoristvorm.

### Zo lees je een vervoeging

De drie vormen hieronder tonen hetzelfde werkwoord in drie personen — het patroon uit les 06.
